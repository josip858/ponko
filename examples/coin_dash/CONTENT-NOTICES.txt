Coin Dash: content notices
==========================

Coin Dash is a reference game for the Ponko engine, built only from content
made for it. Nothing in it is taken from another work.

Pictures
--------
assets/coin_dash/coin.png
    The coin: a 32 x 32 picture drawn by a short script for this example.

    (see LICENSE-MIT and LICENSE-APACHE in this package).

The player's disc is drawn in code when the game starts; it is not a file.

Sound
-----
There are no sound files. Every sound effect is a sine tone that the game
synthesizes when it starts.

Text and fonts
--------------
The game ships no font file. Its text is drawn with the default fonts bundled
into the engine by the `epaint_default_fonts` crate; their licenses are
included in THIRD-PARTY-NOTICES.txt together with every other library that is
linked into the game.
